# Mamun015 Zangetsu Sources

Zangetsu অ্যাপের জন্য BDIX সোর্স সংগ্রহ। লোকাল নেটওয়ার্কের BDIX ফাইল সার্ভার
থেকে মুভি, সিরিজ আর অ্যানিমে সরাসরি ব্রাউজ করে চালানো যায়।

এখন আছে: **DhakaFlix** (মুভি / সিরিজ / অ্যানিমে)। ভবিষ্যতে আরও BDIX সাইট যোগ
হবে — প্রতিটি সাইটের নিজস্ব `sources/<সাইটের-নাম>.js` ফাইল থাকবে।

> ⚠️ এই সোর্সগুলো শুধু BDIX-সংযুক্ত লাইনে কাজ করে। অন্য নেটওয়ার্কে সার্ভারগুলো
> ধরা পড়ে না, তাই লিস্ট ও স্ট্রিম ফাঁকা থাকে।

## ইনস্টল

1. Zangetsu অ্যাপ খোলো → **Sources** ট্যাব
2. **Zangetsu Sources** (JS সোর্স) সেকশনে যাও
3. **Add repository** চাপো, এই লিংকটা দাও:

```
https://raw.githubusercontent.com/Mamun015-Zangetsu/main/index.json
```

4. লিস্টে আসা সোর্সগুলো ইনস্টল করো

## এখনকার সোর্সগুলো

| সোর্স | কী আছে |
|---|---|
| **DhakaFlix Movies** | English Movies, English 1080p, Hindi, South Indian (+Hindi Dubbed), Kolkata Bangla, Foreign Language, IMDb Top 250, 3D, আর ভাষা-ভিত্তিক (Japanese, Korean, Chinese, Bangla Dubbing, Pakistani) |
| **DhakaFlix Series** | TV & Web Series, Korean TV & Web Series, Cartoon TV Series, Awards & TV Shows, WWE & AEW Wrestling, Documentary |
| **DhakaFlix Anime** | Anime TV Series, Animation Movies, Animation Movies 1080p |

ডিটেইল পেজে টাইটেলের আসল পোস্টার, গল্প, রেটিং, কাস্ট আর ট্র্যাকিং আইডি TMDB থেকে
আসে (টাইটল আর বছর মিলিয়ে দেখা হয়, না মিললে সার্ভারের নিজস্ব পোস্টারই থাকে)।

## Auto Resolve (Z Mode) দ্রুত রাখা

অ্যাপের Auto Resolve প্রতি সোর্সে **৫ সেকেন্ড** দেয় (মিল → এপিসোড → স্ট্রিম)। তাই:

- সার্চ শুধু ওই ক্যাটাগরির ফোল্ডারগুলোর ভেতরে হয় (পুরো শেয়ারে নয়), আর বড় ফোল্ডার ভাগ করে ছোট বাকেটে ঢোকে — তাই সাধারণত ১–২ সেকেন্ড
- সার্চের প্যাটার্ন টাইটেলের **যেকোনো গুরুত্বপূর্ণ শব্দের** সাথে মেলে ("Demon|Slayer"), তাই ক্যাটালগের নাম আর ফোল্ডারের নাম আলাদা হলেও খুঁজে পায়
- **টাইটেল পরিষ্কার রাখা জরুরি**: Zangetsu টাইটেল হুবহু মিলিয়ে সোর্স মেনে নেয়, আর
  সে শুধু বছর/সিজন/কোয়ালিটি ছাড়ে — "(TV Cartoon 2019–2024)" বা "AMZN" থেকে
  গেলে মিল খেত। তাই সব বন্ধনী ফোল্ডার, বছর আর প্ল্যাটফর্ম ট্যাগ সরানো হয়।
- `getEpisodes` টিএমডিবির তথ্য আনে না — সবচেয়ে দ্রুত পথ
- অন্য রিলিজ খোঁজার কাজটা ১.৮ সেকেন্ডে সীমিত, তাই প্রোবের সময় পুরো সময় খরচ হয় না

## কীভাবে কাজ করে

- সার্ভারের নিজস্ব ডিরেক্টরি API ব্যবহার করে ফোল্ডার লিস্টিং আর **রিকার্সিভ
  regex সার্চ** — তাই সার্চ ১–৩ সেকেন্ডে আসে, কোনো আলাদা ইনডেক্স লাগে না।
- API বন্ধ থাকলে সার্ভারের HTML ডিরেক্টরি টেবিল পার্স করে ফলব্যাক কাজ করে।
- ভিডিও ফাইল সার্ভার থেকে সোজা আসে এবং Range request সাপোর্ট করে, তাই সিক,
  রিজিউম, ডাউনলোড — সবই কাজ করে, কোনো প্রক্সি লাগে না।
- সার্চ পুরো সার্ভারে হয় (প্রতিটা সার্ভার শেয়ারে একটি রিকোয়েস্ট), তাই নতুন ফোল্ডার
  যোগ হলেও সেটা খুঁজে পাওয়া যায় — `CATEGORIES` অ্যারে না জানালেও।
- একটি ফাইল, তিনটি sourceId: `dhakaflix_movies`, `dhakaflix_series`,
  `dhakaflix_anime`। কোন সোর্সে কী যাবে তা `CATEGORIES` অ্যারে ঠিক করে।
- একই টাইটে ভিন্ন কোডেকের একাধিক ফাইল থাকলে যেটা ফোনে চলবে সেটা আগে দেখানো হয়
  (MP4 / H.264 আগে, HEVC 10-bit শেষে), বাকিগুলো আলাদা সোর্স হিসেবে থাকে।
- **HEVC 10-bit** ফাইল বেশিরভাগ বাজেট ফোনে ডিকোড হয় না। সেই ফাইলটির বদলে
  একই ছবির **অন্য রিলিজ** (সাধারণত 720p/1080p H.264) সার্ভারে থাকলে সেটাও সোর্স হিসেবে
  যোগ হয়, আর অ্যাপ সেটিই আগে বেছে নেয় — তাই কালো স্ক্রিনের বদলে ছবি চলে। 1080p
  HEVC অপশনটাও সোর্স শিটে থাকে, ডিকোডার সফটওয়্যারে দিলে সেটাও চলে।
- **উচ্চতম 1080p** — 4K (2160p) ফাইল কখনো আগে বেছে নেওয়া হয় না; ফোনের ব্যাটারি ও
  ডিকোডার দুটোই বাঁচে। 1080p H.264 বা 8-bit HEVC থাকলে সেটিই আগে আসে।

## নতুন সাইট যোগ করার নিয়ম

1. `sources/` ফোল্ডারে `<সাইটের-নাম>.js` নামে একটি ফাইল বানাও (অন্য সাইটের
   ফাইলটি কপি করে ক্যাটাগরির URL বদলে দাও)
2. `index.json`-এ নতুন একটি এন্ট্রি যোগ করো:

```json
{
  "id": "<সাইটের-নাম>_movies",
  "name": "<সাইটের নাম> Movies",
  "version": "1.0.0",
  "type": "movie",
  "lang": "en",
  "file": "sources/<সাইটের-নাম>.js",
  "logo": "https://raw.githubusercontent.com/Mamun015-Zangetsu/main/logo.png"
}
```

3. প্রোভাইডার কনট্র্যাক্ট: `getInfo`, `getHome`, `popular`, `search`,
   `getDetail`, `getEpisodes`, `getVideoSources` — প্রতিটা ফাংশনের জন্য
   [Zangetsu-র `providers/_template.js`](https://github.com/Spyou/Zangetsu/blob/main/providers/_template.js)
   দেখো।

## সীমাবদ্ধতা

- ফাইল নেম থেকে টাইটেল, বছর, সিজন আর এপিসোড নম্বর পার্স করা হয় — সার্ভারে
  আলাদা মেটাডেটা নেই, তাই গল্প/কাস্ট দেখানো হয় না।
- প্লেব্যাক ও ডাউনলোড স্পিড তোমার BDIX লাইন আর সার্ভারের উপর নির্ভর করে।
- নতুন কোডেক (যেমন HEVC 10-bit) সব ফোনে চলে না — সেক্ষেত্রে Zangetsu-র
  Settings → Player → Video decoder → "Software (most compatible)" কাজে দেয়।
